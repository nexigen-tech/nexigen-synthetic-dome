# Навык анализа Rust проектов

Используй этот навык, когда пользователь просит проанализировать структуру, качество, безопасность или сложность Rust-кода, а также для автоматического приведения кодовой базы к идиоматичному стилю Rust.

## Инструкция по выполнению для Агента:
1. Убедись, что в системе установлены компоненты Rust (`clippy`, `rustfmt`).
2. Перейди в корень анализируемого проекта (директорию, где находится файл `Cargo.toml`).
3. Запусти скрипт анализа, находящийся в папке навыка: `python3 ~/.opencode/skills/rust-project-analyzer/analyzer.py .`
4. Внимательно изучи сгенерированный скриптом JSON-отчет:
   - Массив `auto_fixes_applied` содержит действия, которые скрипт уже успешно применил к коду «на лету» (например, автоматическое исправление предупреждений Clippy).
   - Массив `issues` содержит только те критические ошибки или проблемы форматирования, которые не удалось исправить автоматически.
   - Массив `suggested_fixes` содержит команды, требующие подтверждения пользователя (например, `cargo update` для устранения уязвимостей).
5. Выведи пользователю красивый, структурированный markdown-отчет со следующими секциями:
   - **📊 Метрики и Сложность**: Общее количество строк и число найденных `unsafe`-блоков.
   - **⚡ Примененные авто-исправления**: Что скрипт уже успешно исправил в коде сам.
   - **⚠️ Оставшиеся проблемы**: Проблемы, требующие внимания разработчика или агента.
   - **🛡️ Рекомендуемые действия**: Предложения по запуску команд обновлений или форматирования.
