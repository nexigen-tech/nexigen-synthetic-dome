# Навык анализа C++ проектов

Используй этот навык, когда пользователь просит проанализировать структуру, метрики, объём или сложность C++ кода в текущем репозитории.

## Инструкция по выполнению для Агента:
1. Убедись, что в системе установлены утилиты `cloc` и библиотека `lizard` (через pip). Если их нет, вежливо попроси пользователя установить их или используй доступный пакетный менеджер.
2. Запусти скрипт анализа, находящийся в этой же папке: `python3 ./analyzer.py .` (где `.` — путь к анализируемому проекту).
3. Прочитай сгенерированный JSON-отчет.
4. Выведи пользователю красивый, структурированный markdown-отчет с ключевыми выводами и рекомендациями по рефакторингу сложных функций.
